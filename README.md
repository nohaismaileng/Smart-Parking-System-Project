🚗 Smart Parking System Project

Implemented a complete Arduino-based Smart Parking System featuring:

✅ 4 ultrasonic sensors for parking slot detection
✅ Automatic entry and exit gates using servo motors
✅ LCD display showing available parking slots
✅ Red/Green LED indicators for occupied and free slots
✅ IR sensors for vehicle entry/exit detection
✅ Buzzer alert when parking is full
✅ Emergency and reset control buttons

🛠️ Technologies & Components:

* Arduino Mega
* Servo Motors
* HC-SR04 Ultrasonic Sensors
* IR Sensors
* I2C LCD Display
* LEDs & Buzzer

The system automatically monitors parking availability and controls gate access in real time.
